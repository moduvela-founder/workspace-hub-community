# 工作空间规范入口

这里维护产品、工具、框架、流程、技能、AI 生成作品和资料的登记与开发文档约定。Workspace Hub 自身是独立工具项目；目标项目的规则、批准要求和验收证据仍是事实来源。

按任务读取；已知目标入口时直接读取，不为导航重复阅读本目录、技能或全部关联文档。普通问答不加载全部规范：

| 任务 | 读取 |
| --- | --- |
| 其他产品/工具项目采用本规范、更新其规则入口 | [项目采用的共享规则](project-rules.md) |
| 启动项目/新功能、约定本轮交付范围，或重整开发主线 | [DEMO 验证与产品化推进](delivery-workflow.md)，含新需求与旧会话的复制提示词 |
| 网页/桌面/移动界面的设计、实现、文案与布局审查 | [界面信息与视口验收](ui-delivery.md)，含 Mac 内容区尺寸、一屏指标与滚动边界 |
| 首次生成构建/测试输出、阶段收尾/临时工作区退役，或大文件、Docker、发布包、游戏库及迁移 | [存储与输出约定](storage-and-outputs.md)；机器路径、卷和私有保留决定见实际环境规程 |
| 登记资产、关联仓库、查找可复用能力、短引用或布局边界 | [资产模型](asset-model.md) |
| 登记或启停本地 MCP/桥接进程、交接服务接入信息 | [本地服务与接入](local-services.md)，再读对应工具指南 |
| 接入角色/技能/参考资料包、查询包内成员或正文 | [资料包与内容索引](knowledge-collections.md) |
| 新项目初始化、实施后更新状态、整理过多文档 | [文档契约](document-contract.md) |
| 用户明确要求手动整理已结束会话的问题、决策与证据 | [session-closeout 技能](../../skills/session-closeout/SKILL.md)；显式调用，不在普通收尾自动执行 |
| 旧项目首次梳理、批量登记、冲突与副本处理 | [整理流程](onboarding.md) |
| 执行以上工作 | [workspace-catalog skill](../../skills/workspace-catalog/SKILL.md) |

首次相关任务、上下文缺失或开始下一项管理文档写入前，在 Hub 根运行 `node scripts/hub.mjs rules --summary --json`；有本会话指纹时加 `--since HASH`。摘要仅返回总指纹和变化标记；首次或缺少正文时仍读相关规范。指纹变化后用 `rules --json` 对比已保留的逐文件指纹；没有旧清单时重读当前任务相关规范。未变化且正文仍在上下文中才可复用。指纹只覆盖 Hub 的 AGENTS、规范、模板和登记技能，不证明项目实时状态，也不刷新 Codex 自动注入的指令链。

格式版本为 `schemaVersion: 1`。持久字段及解释只维护在下列契约中；临时日志和扫描结果不进入 AGENTS.md。目录是初步登记，不代表所有项目已梳理完毕。

新会话拿到 `workspace-hub:<asset-id>`、Hub 根目录和名称后，在该 Hub 根运行 `node scripts/hub.mjs resolve --id ID` 取得阅读入口；查找能力用 `search --query TEXT`，生成短引用用 `reference --id ID`。这些命令只读，不加载历史长摘要，也不执行设备、项目代码或远端命令。解析不能代替读取目标项目的适用 AGENTS。

解析中的 `instructions` 也包含关联范围的候选路径，按选中来源及实际动作读取，不将全部路径视为无条件必读。只读消费共享文档不继承 Hub 应用开发命令；修改 Hub 内容或执行其能力时读取适用的 Hub 指令和操作指南。

解析结果中的 `services` 指向工具接入指南和只读状态命令；需要当前端点时再查询，不把端口或运行快照塞进短引用。侧栏“MCP 服务”复用工具/技能卡；进程状态与项目开发阶段分别维护，启动服务不会自动连接应用或向 Codex 会话注入工具。
