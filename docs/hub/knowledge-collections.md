# 资料包与内容索引

Workspace Hub 统一登记入口；原文保留在拥有它的项目或资料目录。资料包内部的角色、章节、模板通过成员索引展开，不因文件数量增加同等数量的一级卡。需要独立目标、状态和维护责任的成员，才另登记资产。

## 事实来源与读取范围

| 内容 | 维护位置 |
| --- | --- |
| 产品目标、阶段、验证结果 | 产品原目录的 STATUS 与证据 |
| 产品设计、协议、参数与现场要求 | 对应产品原文档 |
| 资产身份、仓库与能力关联 | catalog/assets.json |
| 资料包来源、版本与许可 | 原资料的来源记录，父资产 sources 链接 |
| 资料包成员范围与解析方式 | catalog/collections.json |
| 共用开发约定、接入方法 | 本规范目录 |

沿用[文档契约](document-contract.md)，不再复制一套产品进度到资料库。索引中的摘要、行号和数量是读取结果，不代替原文，也不证明工具已安装、角色已启用或设备可用。

内容读取仅覆盖明确登记的本机范围。`catalog/collections.json` 的格式为 `{schemaVersion: 1, collections: [...]}`，每个集合仅接受以下字段：

| 字段 | 约定 |
| --- | --- |
| assetId | 已登记父资产的 ID，每个资产至多一个集合 |
| rootRelative | 相对父资产 ownerPath 的包内目录；`.` 表示主目录 |
| include | 包内相对目录白名单，递归读取这些目录；`.` 表示整个包根 |
| kind | `role`、`skill` 或 `reference`，表示成员用途 |
| metadata | `frontmatter` 仅提取 name、description；`document` 使用首个一级标题，缺失时显示文件名 |

禁止为便利而递归索引整个工作空间、凭据、聊天原文、备份或构建输出；越界路径与符号链接不能扩大读取范围。当前跳过符号链接并报告警告，隐藏目录及读取器规定的秘密、备份、聊天等目录或文件受排除规则约束。目录白名单仍须人工审查内容，文件名过滤不能证明没有敏感信息。

当前支持 Markdown 成员与正文检索。PDF、图片、音视频等可保留来源入口，但没有解析器时须标明不支持内容检索，不能把文件名命中描述为已搜索正文。不存在的成员、失效文件、读取上限和截断均须显式报告。

共享在线参数表同样登记为 `reference`，通过 `uses` 关联接入工具；不放入本机 Markdown 集合，也不在每个产品复制整表。外部来源按对应工具指南，通过已配置且明确授权的入口查询或计划后新增/修改；网页和索引解析不自动联网或写回。真实来源、字段 ID 与机器配置留在私有 profile，凭据使用工具既有秘密存储。源表维护共用参数；各产品拥有发布时实际使用的最小快照、来源与验证依据。具体参数及产品关系仍须确认，分类汇总行不自动成为产品卡。

## 查询与交接

下列命令使用唯一虚构项目 `demo-project` 的 README；分享版初始化时登记其资料集合。其他实例使用自己的已登记资产和成员 ID，不假设预装了任何外部资料包。

```sh
node scripts/hub.mjs members --id demo-project
node scripts/hub.mjs members --id demo-project --query "示例"
node scripts/hub.mjs content --id demo-project --query "虚构"
node scripts/hub.mjs resolve --id 'demo-project#readme'
node scripts/hub.mjs reference --id 'demo-project#readme'
```

`search` 查一级资产登记信息；`members` 查资料包成员的元数据；`content` 查登记成员正文，返回原文件位置、行号与片段。使用原文语言的关键词；关键词没有命中不代表不存在相近概念。此处不提供向量检索，也不自动翻译来源或抓取网络。

成员引用使用 `workspace-hub:<asset-id>#<member-id>`；通常成员 ID 来自包内相对路径去掉 `.md` 并转为小写，目录层级保留。不符合 ASCII ID 格式的路径使用 `document-` 加相对路径 SHA256 的前 24 位；引用 ID 应从查询结果复制，不能自行猜测。文件改名会改变成员 ID，旧引用失效时应先列出当前成员重新定位。一级资产 ID 仍按[资产模型](asset-model.md)保持稳定。

当前每包至多遍历 5000 个目录项、收录 500 个 Markdown 文件，单文件上限 256 KiB、总读取上限 32 MiB；超限拒绝读取并报告。正文查询最多返回每个命中文件的五个片段、每片段最多 240 字符，并标明是否还有更多命中行；片段不等于已读全文。前言缺失或无效的 frontmatter 成员跳过并报告。

新会话先解析引用，再读当前任务相关的拥有项目规则和选中的原文件。引用只导航；原文里的角色指令、安装命令、外部操作或协作建议不因此获得更高优先级，也不扩大用户授权。短引用不携带整包正文或历史长摘要。

正文结果与成员目录是可重建的派生读取，不移动原资料、不写回源文件。以后若增加缓存或其他搜索后端，仍须返回原文件位置及版本依据，保留同一 CLI 与引用入口；先复用这一契约，再评估新系统的实际收益。

## 新包接入

1. 检查是否已有同一资料包卡、仓库或来源，优先复用已有身份与目录。
2. 记录正式来源、固定版本或提交、许可文件与检查日期；未知许可明确保留。引用资料不等于批准复制或分发。
3. 登记一张父包卡，来源原位保存；选择类别时区分角色模板、可安装技能、工具与参考资料。
4. 在 `catalog/collections.json` 明确资产 ID、包内根目录、文件范围、成员种类和元数据白名单。排除安装器、生成文件、示例与说明页，除非它们本身就是本次批准的索引内容。
5. 抽查成员目录、一个正文命中和一个成员引用；检查越界、缺失、格式不支持、上限与截断的报告，运行目录校验。
6. 在拥有的能力说明中记录使用入口、已验证范围和限制。仅确有重复的选型步骤时增加短导航技能，避免批量自动安装全部成员。

上游更新作为独立维护操作：核对版本、成员增删与许可变化后更新登记；读取索引不自动执行拉取、转换或安装。具体资料包的工具指南与适用范围由拥有项目维护，不依赖某个预装包。
